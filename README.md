# Olivija's Math Quest

A single-page math practice game for 1st and 2nd graders, following the US Common Core standards for grades 1 and 2.

- 17 worlds (counting, adding, clock, coins, fractions, story problems and more), 3 levels each
- Speed Round (60 seconds), Mix It Up, and a Sticker Book to spend coins on
- Wrong answers come back at the end of the round for extra practice
- Progress is saved in the browser (localStorage)

## Play

Open `index.html` in any browser — no build step or dependencies.
